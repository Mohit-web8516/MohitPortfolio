## Add a Profile Photo

1. Create an `assets` folder in the project directory.
2. Add your approved profile photograph.
3. Rename it to `mohit-photo.jpg`.
4. In `index.html`, use the following image element where your profile image should appear:

```html
<img src="assets/mohit-photo.jpg" alt="Portrait of Mohit Shrivastav">
```

Make sure the image path matches the actual filename.

## Run Locally

No build tools or backend are required for the static frontend.

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Publish Using GitHub Pages

1. Create a public GitHub repository, for example, `Mohit-Portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to deploy your website.

Your website URL will follow this format:

`https://YOUR-USERNAME.github.io/Mohit-Portfolio/`
